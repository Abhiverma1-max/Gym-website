
# 🏋️ John's Fitness Hub – Gym Website

A modern, responsive gym website built using HTML, CSS, JavaScript, and Bootstrap.

## 🌐 Live Demo
[Visit John's Fitness Hub](https://gym-website-eight-azure.vercel.app/)

## ✨ Features
- Modern and responsive design
- Home and About sections
- Gym training programs
- Membership pricing plans
- Why Choose Us section
- Customer testimonials
- Booking / Contact form
- Smooth scrolling and animations
- Mobile-friendly layout

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap
- jQuery

## 📂 Project Structure
```text
Gym-website/
├── index.html
├── gym.css
├── images/
├── css/
├── js/
└── jquery/
```

## 🚀 Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Abhiverma1-max/Gym-website.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
